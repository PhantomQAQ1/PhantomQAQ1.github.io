把键盘垫换成奶油色，加了一盏很暗的灯。

改造的起因很无聊：某天下午我盯着屏幕，突然发现桌面上没有一样东西是我选的。显示器是公司发的，鼠标是买显示器送的，连那张鼠标垫都来自某个展会。

## 只做三件事

预算有限，所以只做三件事：

1. 换一块奶油色的桌垫，把冷色调压掉；
2. 加一盏亮度只有 15% 的小灯，光从侧面进来；
3. 把常用的三样东西贴上胶带，做记号。

第三件听起来最没用，但效果最好。胶带是那种很薄的纸胶带，撕下来不留痕。贴完之后，桌面忽然有了「被使用过」的痕迹，不像是租来的工位了。

> 「效率是给别人看的，舒不舒服只有手知道。」

## 一点技术细节

如果你也想给页面加一点这种「手作感」，其实只要几行 CSS：

```css
.tape {
  background: #ffe8a3cc;
  clip-path: polygon(0 7%, 100% 0, 100% 93%, 0 100%);
}
```

不是必须的，但会让边角变得不那么锋利。

- 桌垫：奶油白，比纸稍微黄一点；
- 小灯：色温 2700K，亮度 15%；
- 胶带：三卷，米黄、樱粉、薄荷。
